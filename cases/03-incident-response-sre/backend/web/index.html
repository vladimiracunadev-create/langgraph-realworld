Incident Response SRE — Caso 03

Cuando un servicio de producción falla, cada segundo cuenta. Este caso orquesta la respuesta completa a un incidente de infraestructura: ingiere las señales de alerta, clasifica la severidad (P1 crítico, P2 urgente, P3 menor), escala automáticamente a PagerDuty si es P1, selecciona el runbook de remediación correcto, solicita aprobación humana antes de ejecutar acciones destructivas, aplica los pasos de remediación (escalar réplicas, rollback, ajuste de timeouts), verifica la recuperación consultando métricas y genera el postmortem final. En modo DEMO opera con datos reales sin necesidad de credenciales externas.
