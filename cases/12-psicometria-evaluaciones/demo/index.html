Caso 12 — Psicometría y Evaluaciones OPERATIVO
Este caso ya tiene un backend FastAPI + LangGraph operativo.

Cómo abrir la UI operativa

El backend operativo expone su propia interfaz web en http://localhost:8012/web/.

Para levantarlo: 

cd cases/12-psicometria-evaluaciones/backend
docker compose up --build

# o desde la raíz del repo
docker compose up case12

Qué hace el caso

Validación psicométrica de instrumentos: revisión experta, ensamblado balanceado por concepto, pilotaje simulado (Rasch‐like dicotómico o Likert), análisis (α de Cronbach, dificultad, discriminación item-total, DIF entre grupos), loop de revisión psicométrica con tope, calibración de baremos, informes individuales por banda y reporte ejecutivo grupal.
