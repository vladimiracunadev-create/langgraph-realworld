DevEx: Revisión Automatizada de PRs — Caso 19

Cada Pull Request que llega al repositorio puede introducir vulnerabilidades de seguridad sin que nadie las note. Este caso analiza automáticamente el diff de un PR detectando inyección SQL, uso de eval(), credenciales hardcodeadas y shell injection; evalúa calidad del código (imports sin usar, funciones largas, comentarios pendientes) y verifica cobertura de tests. Con todo ello calcula el nivel de riesgo (HIGH / MEDIUM / LOW), toma una decisión (solicitar cambios, aprobar con observaciones o aprobar) y postea el comentario de revisión en GitHub. En modo DEMO trabaja con un PR de ejemplo que incluye vulnerabilidades reales para demostrar el análisis.
