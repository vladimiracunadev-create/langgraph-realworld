Generación y mantenimiento de documentación técnica con QA en loop

La documentación técnica suele desactualizarse antes que el siguiente release. Este agente LangGraph escanea el repositorio, extrae artefactos (endpoints, schemas, funciones, tests, changelog), genera un outline adaptado al tipo de proyecto, redacta cada sección con datos reales del código y aplica un ciclo de QA con loop condicional (tope de 3 iteraciones) para corregir secciones que no superan el umbral de score. Publica el documento final en Markdown con el diff de cambios. Determinista en DEMO; resumen narrativo opt-in con LLM.
