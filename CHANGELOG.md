# Changelog

## 🚀 v3.7.0 - 2026-04-02

### ✨ Added
- 🛠️ **Caso 02 Elevado a Operacional**: Rediseño completo para ambiente SRE e integraciones IT.
- 🎨 **Frontend Interactivo (Caso 02)**: Agregadas píldoras de sugerencias rápidas, tracker de eventos en NDJSON y consola de terminal SRE dinámica.
- 🧠 **Mejoras Lógicas en LangGraph (Caso 02)**: Agregado nodo `enrich_ticket` (consultas CMDB vía JSON local), nodo `approval_check` (manejo de HitL), y condiciones rígidas pre-ejecución para atrapar saludos o texto fuera de límite (`unsupported`).
- 👔 **Traducción Comercial del Portal Raíz**: `index.html` del repositorio readaptado hacia negocio como "Catálogo de Automatizaciones IA", cambiando lenguaje dev/backend a descripciones claras del valor.

## v3.6.0 - 2026-03-13

### Added

- Centro de APIs compartido para el portal y los casos operativos 01, 09, 10 y 13.
- Formulario de credenciales opcionales con nombre de variable, caso vinculado, enlace oficial y exportación `.env` por caso.
- Guía documental explícita para instalar primero y completar APIs después sin bloquear el modo DEMO.

### Changed

- README raíz, docs técnicas, roadmap, recruiter guide, Hub y wiki local sincronizados a `v3.6.0`.
- Taxonomía de estados alineada: caso 01 como `Operational (v3.6.0)` y casos 09, 10 y 13 como `Industrial (v3.6.0)`.
- Casos industriales y operativos documentados con activación profesional de integraciones desde `.env.example` o desde la interfaz.
