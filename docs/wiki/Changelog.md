# Changelog

## v3.6.0 - 2026-03-13

### Added

- Centro de APIs compartido para el portal y los casos operativos 01, 09, 10 y 13.
- Formulario de credenciales opcionales con nombre de variable, caso vinculado, enlace oficial y exportación `.env` por caso.
- Guía documental explícita para instalar primero y completar APIs después sin bloquear el modo DEMO.

### Changed

- README raíz, docs técnicas, roadmap, recruiter guide, Hub y wiki local sincronizados a `v3.6.0`.
- Taxonomía de estados alineada: caso 01 como `Operational (v3.6.0)` y casos 09, 10 y 13 como `Industrial (v3.6.0)`.
- Casos industriales y operativos documentados con activación profesional de integraciones desde `.env.example` o desde la interfaz.
