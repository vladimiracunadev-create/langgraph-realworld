# Especificaciones Técnicas

> [!NOTE]
> **Versión**: 3.6.0 | **Estado**: Industrial | **Audiencia**: Seniors, DevOps

## Configuración de credenciales

- `.env.example` define la base portable por caso.
- `.env` sigue siendo opcional para demos locales.
- el portal y las UIs operativas permiten guardar credenciales opcionales en navegador y exportar el `.env` por caso.
- la interfaz informa qué variable corresponde a qué caso y dónde obtenerla.
